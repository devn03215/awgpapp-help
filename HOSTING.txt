GitHub Pages for the AWGP Help Center (public repo under devn03215).

Live URL (after deploy):
  https://devn03215.github.io/awgp-help/

Same pattern as:
  https://devn03215.github.io/awgp-share/
  https://devn03215.github.io/awgp-books/
  https://devn03215.github.io/privacy-policy/

## One-time setup

1. Create a public repo: https://github.com/new
   Name: awgp-help
   Owner: devn03215
   Do not add README (we copy from awgp-mobile).

2. Enable Pages: Settings → Pages → Deploy from branch → main → / (root)

## Deploy updates

From awgp-mobile (source of truth):

```powershell
# Copy site into the Pages repo
Copy-Item c:\dev\git\awgp-mobile\help-landing\* c:\dev\git\awgp-help\ -Recurse -Force

cd c:\dev\git\awgp-help
git add -A
$env:GIT_AUTHOR_NAME="devn03215"
$env:GIT_AUTHOR_EMAIL="devn03215@gmail.com"
$env:GIT_COMMITTER_NAME="devn03215"
$env:GIT_COMMITTER_EMAIL="devn03215@gmail.com"
git commit -m "Update help center"
git push
```

First-time clone after creating the empty repo:

```powershell
git clone https://github.com/devn03215/awgp-help.git c:\dev\git\awgp-help
# then copy and push as above
```

## Custom domain later

Add CNAME in repo root (e.g. help.awgp.org) and configure DNS + GitHub Pages custom domain.
